## Title
Food Ordering System

## Objective
The objective of this project is to develop an online food ordering system which makes ordering food simple and fast.

## Problem Statement

Food Ordering System is a simple online food ordering program written in Python language. It allows the user to view available menu, select food to purchase, manage the food cart by adding and removing items from the cart, gives discount and generate a detailed final bill.

## Target Users

Students who are learning Python programming .

## Project Flow

- Display the Resturant menu.
- Show the available food items.
- Ask the user how many food items they want to purchase.
- Take the serial number of each selected item(s).
- Add valid selections to the cart.
- Ask whether the user wants to add or remove food items.
- Update the cart if required.
- Display the final cart.
- Generate the final bill and give discount.

## Project Outcome

The final outcome is a simple interpreter based Food ordering system that demonstrates the basic process of selecting food items, managing a food cart, and generating a discounted bill.
